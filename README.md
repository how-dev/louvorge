# Louvor GE

Página mobile-first do Ministério de Louvor Geração Efraim, com acesso rápido ao repertório e às escalas.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main`, a pasta `/ (root)` e salve.

O site não precisa de compilação ou instalação de dependências.
